# 🏠 Tehran House Price Prediction

پیش‌بینی قیمت خانه در تهران با استفاده از مدل‌های یادگیری ماشین (CatBoost / XGBoost / Random Forest) بر اساس ویژگی‌هایی مثل متراژ، تعداد اتاق، پارکینگ، انباری، آسانسور و منطقه (Address).

## 📋 ویژگی‌ها (Features)

- پاک‌سازی داده‌ها: حذف مقادیر گمشده و رکوردهای تکراری
- حذف قیمت‌های نامعتبر (Price ≤ 0)
- تبدیل لگاریتمی قیمت (`log1p`) برای بهبود دقت مدل، چرا که توزیع داده نامتقارن است و نمی‌توان داده‌ها را به‌عنوان outlier حذف کرد، زیرا ردیف‌های مهمی از بین می‌روند
- هندل کردن مقادیر متنی (`Address`) با `pd.get_dummies` در تابع جست‌وجوی هایپرپارامتر (`GridSearchCV`)
- جست‌وجوی بهترین هایپرپارامترها با `GridSearchCV` برای سه مدل:
  - XGBoost
  - CatBoost ✅ (مدل نهایی انتخاب‌شده)
  - Random Forest
- ارزیابی مدل با معیارهای `R²` و `RMSE`
- بخش تعاملی برای پیش‌بینی قیمت یک خانه جدید از طریق ورودی کاربر (CLI)
- تبدیل قیمت پیش‌بینی‌شده به دلار بر اساس نرخ ارز وارد شده توسط کاربر

## 📊 دیتاست

فایل مورد نیاز: `tehranHprice.csv`

ستون‌های اصلی مورد استفاده:

| ستون | توضیح |
| --- | --- |
| `Area` | متراژ |
| `Room` | تعداد اتاق |
| `Parking` | دارای پارکینگ (0/1) |
| `Warehouse` | دارای انباری (0/1) |
| `Elevator` | دارای آسانسور (0/1) |
| `Address` | منطقه/محله |
| `Price` | قیمت (تومان) — متغیر هدف |
| `Price(USD)` | قیمت به دلار (در آموزش مدل استفاده نمی‌شود، چرا که تأثیر معناداری بر مدل ندارد) |

## 🚀 نحوه اجرا

1. فایل `tehranHprice.csv` را در همان مسیر اسکریپت قرار دهید.
2. اسکریپت را اجرا کنید:

```bash
python main.py
```

3. مدل CatBoost به‌صورت خودکار آموزش داده می‌شود.
4. سپس برنامه به‌صورت تعاملی اطلاعات خانه جدید را از شما می‌پرسد:

```
مثال:
area : 120
room : 2
parking(0/1) : 1
Warehouse(0/1) : 1
Elevator(0/1) : 1
Address : Niavaran
Current USD rate: 60000
```

5. خروجی شامل قیمت پیش‌بینی‌شده به تومان و معادل آن به دلار خواهد بود.

> ⚠️ نکته: مقدار `Address` باید دقیقاً یکی از مناطق موجود در دیتاست باشد، در غیر این صورت پیام خطا نمایش داده می‌شود.

## 📈 نتایج مدل‌ها (GridSearchCV + pd.get_dummies)

| مدل | R² (Train) | R² (Test) | RMSE (Test) |
| --- | --- | --- | --- |
| XGBoost | 84.56% | 67.94% | 318,478,591 |
| CatBoost | 86.23% | 68.71% | 314,591,703 |
| Random Forest | 93.52% | 69.30% | 311,630,290 |

مدل نهایی استفاده‌شده در پروژه **CatBoost** با پارامترهای بهینه زیر است:

```
iterations=500, depth=4, l2_leaf_reg=1, learning_rate=0.1, colsample_bylevel=1, subsample=1
```

> ⚠️ نکته: از آنجا که CatBoost خودش قادر به هندل کردن مقادیر متنی (categorical) است، هنگام آموزش مدل نهایی بخش `pd.get_dummies` کامنت می‌شود و به‌جای آن از پارامتر `cat_features` استفاده می‌شود.

## 📝 توضیحات تکمیلی

- بخش‌های مربوط به `GridSearchCV` برای هر سه مدل در کد به‌صورت کامنت نگه داشته شده‌اند تا در صورت نیاز قابل اجرای مجدد باشند (زمان‌بر هستند).
- متغیر هدف (`Price`) با `log1p` تبدیل شده و در زمان ارزیابی با `expm1` به مقیاس اصلی بازگردانده می‌شود.
- معیارهای `R²` و `RMSE` دقت مدل را در پیش‌بینی عدد قیمت می‌سنجند، نه دقت آن را در برازش معادلات الگوریتمی داخلی مدل.
